## ファイル

- `index.html` : 診断ページ本体（12問・4タイプ自動判定）

## 診断仕様

| 項目 | 内容 |
|---|---|
| タイトル | あなたの善意、ちゃんと届いてる？ |
| 形式 | 12問 × 4択 |
| タイプ | 先回り／正解を渡す／心配／信じて引き出す |
| 判定 | 最多得点のタイプ（同点時は複数タイプを案内） |

## 使い方（HTML版を使う場合）

1. `index.html` をWeb上に公開する
2. 公開後のURLを、UTAGEの友だち追加メッセージのボタンに設定する
3. Instagramからの入口は必ず UTAGE の LINE登録 URL を使う

## 結果画面の動き

1. **詳しい解説** … 結果ページ内にタイプ別で表示
2. **LINEにキーワードを送る** … 結果画面に出るキーワードをLINEトークに送信
3. **UTAGEキーワード応答** … タイプ別の追加解説が自動返信

### キーワード一覧（UTAGE設定済み）

| タイプ | 送るキーワード |
|---|---|
| 先回りサポート | `先回り` |
| 正解を渡したい | `正解を渡す` |
| 心配で見守れない | `見守れない` ※「心配」は既存キーワードと衝突するため不可 |
| 信じて引き出す | `引き出す` |
| タイプ不明時 | `当たってます` → キーワード一覧を案内 |

- スマホで1問ずつ表示されるか
